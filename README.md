# AI Hub для GitHub Pages

Готовый статический интерфейс универсального ИИ.

## Важно
GitHub Pages может бесплатно хостить HTML/CSS/JS, но сам по себе не предоставляет бесплатную безлимитную генерацию текста, изображений или видео. API-ключ нельзя безопасно зашивать в публичный frontend.

Этот проект поэтому:
- работает как обычный GitHub Pages сайт;
- поддерживает OpenAI-compatible `/chat/completions`;
- хранит введённый ключ только в localStorage браузера;
- имеет режимы чат / изображение / видео / код;
- не обещает несуществующую «безлимитность».

Для production лучше поставить небольшой backend/proxy (например Cloudflare Worker/Vercel/свой сервер), где API-ключ хранится на сервере. Лимиты при этом определяются выбранным провайдером.
