# Романтическое поздравление — Telegram WebView / GitHub Pages

Сайт оптимизирован для открытия внутри Telegram-бота во встроенном браузере.

## Структура

- `index.html` — сайт;
- `photo.jpg` — главное фото;
- `music.mp3` — музыка;
- `photos/` — фотографии для коллажа.

## Фотографии

Замени изображения в папке `photos`:

`photo1.jpg` … `photo6.jpg`

Сохраняй именно эти имена и путь `photos/...`.

## Для Telegram

Сайт рассчитан на мобильный Telegram WebView:
- viewport с `viewport-fit=cover`;
- поддержка safe-area на телефонах с вырезами/жестами;
- без горизонтального скролла;
- крупные удобные кнопки;
- touch-оптимизация;
- адаптивная фотозона;
- корректная высота через `100svh/100dvh`;
- ограничение случайного масштабирования страницы;
- сохранение вертикального скролла.

Для запуска из Telegram бот должен отправлять пользователю ссылку на опубликованный GitHub Pages сайт.
