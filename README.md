# Романтическое поздравление — GitHub Pages

Файлы:
- `index.html` — сайт;
- `photo.jpg` — сюда нужно положить фотографию девушки;
- `music.mp3` — сюда нужно положить музыку.

После загрузки всех трёх файлов в один репозиторий включи GitHub Pages через Settings → Pages → Deploy from a branch → main → / (root).

Важно: используй музыку, на которую у тебя есть права, либо трек с разрешённой лицензией.
