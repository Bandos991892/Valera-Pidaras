# l3vitov open tool

Статический OSINT-интерфейс для GitHub Pages.

## Установка

1. Создайте публичный GitHub-репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. GitHub → **Settings → Pages**.
4. **Deploy from a branch** → `main` → `/ (root)` → Save.

## Возможности

- адаптация под ПК и телефон;
- фон из предоставленного логотипа;
- неоновый интерфейс в стиле логотипа;
- поиск по ФИО, IP, номеру, username и URL;
- автоматическое определение типа запроса в режиме ALL;
- формирование релевантных ссылок сразу после поиска;
- IP: Google, Bing, Shodan, AbuseIPDB, ARIN, RIPE;
- ФИО: веб-поиск, новости, изображения и публичный LinkedIn-поиск;
- номер: несколько публичных поисковиков и Maps;
- social: GitHub, Reddit, GitLab и поисковики;
- URL/domain: поисковики, VirusTotal, URLScan и SecurityTrails;
- введённые значения не сохраняются сайтом.

### Ограничение GitHub Pages

GitHub Pages — статический хостинг. Настоящее серверное получение данных из API требует backend/serverless-функции и официальных API. Секретные API-ключи нельзя помещать в JavaScript, который публикуется в GitHub.

Инструмент рассчитан на законную работу с открытыми источниками и не подключается к паролям, закрытым аккаунтам или нелегальным базам данных.
