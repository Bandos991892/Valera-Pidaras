# Neon Graph — GitHub Pages

Статический интерактивный просмотрщик для `zodiac-graph.json`.

## Публикация на GitHub Pages

1. Создайте новый GitHub-репозиторий.
2. Загрузите в него **все 4 файла** из этой папки.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните настройки — GitHub выдаст адрес сайта.

Файл `zodiac-graph.json` должен лежать рядом с `index.html`.
